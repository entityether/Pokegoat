# Monster Journey — Kanto Alpha v0.18.1

Juego de aventura Pokémon para navegador.

## Publicar con GitHub Pages

1. Subí `index.html`, `.nojekyll` y `README.md` a la raíz del repositorio.
2. En **Settings → Pages**, elegí **Deploy from a branch**.
3. Seleccioná `main` y la carpeta `/ (root)`.
4. Guardá y esperá a que termine el despliegue.

El archivo `index.html` contiene HTML, CSS, JavaScript y sprites integrados.
